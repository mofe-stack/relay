# data

- **dist.pkl:** for each speaker, the dynamic time warping distance between every test recording and every saved recording. it has no audio in it.
- **whisper_test.csv:** whisper small's chosen phrase and scores for each test recording.

both are made from the easycall dataset (turrisi et al. 2021, cc by-nc 2.0): [paper](https://arxiv.org/abs/2104.02542) and [hugging face](https://huggingface.co/datasets/changelinglab/easycall-dysarthria).
